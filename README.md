# 매크로 테마 밸류체인(공급망) 탐색 에이전트

특정 글로벌 이슈(예: "엔비디아 H200 수요 폭증")를 입력하면, 관련 산업 밸류체인(소재-부품-장비-완제품)을
GPT로 추론하고 GraphRAG 방식으로 대장주 대비 수혜 단계를 계산해, **이미 급등한 대장주 대신 아직
반응하지 않은 2차·3차 수혜주 후보**를 찾아주는 Streamlit 앱입니다. 입력한 투자금을 추천 우선순위
1~3위에 자동으로 배분하는 기능도 제공합니다.

> ⚠️ 참고용 정보 제공 도구이며 투자 조언이 아닙니다. 모든 투자 판단과 결과에 대한 책임은 이용자 본인에게 있습니다.

🔗 **배포된 앱**: https://macro-valuechain-agent.streamlit.app/

## 동작 흐름

```
[이슈 입력]                    사이드바에서 "오늘의 추천 이슈"(웹 검색 기반 자동 추천, 하루 1회 캐싱)
                                또는 "직접 입력" 중 선택
      │
      ▼
[① 밸류체인 추출]              OpenAI(gpt-4o-mini)가 이슈를 소재/부품/장비/완제품 노드와
                                공급·고객 관계(edges)로 구성된 JSON으로 반환
      │
      ▼
[② GraphRAG hop 계산]          networkx로 그래프를 만들고 대장주 기준 BFS로 hop 거리 계산
                                → 1차(대장주)/2차/3차 티어 태깅
      │
      ▼
[③ 종목 매핑 + 주가 조회]      각 노드명을 KRX 상장 목록과 대조해 실존 종목코드 검증
                                (LLM이 지어낸/사명 변경된 종목은 "미확인 종목"으로 자동 제외)
                                → FinanceDataReader로 등락률·현재가 조회 (호출마다 1초 대기)
      │
      ▼
[④ 필터링]                     이미 임계값(기본 15%) 이상 급등한 종목 제외
                                "~에도 불구하고" 식 우회 논리가 담긴 근거는 결정론적으로 제외
                                대장주와 그래프로 연결되지 않은 노드는 추천에서 제외
      │
      ▼
[⑤ 우선순위 산정 + 투자금 배분] hop 거리 → 등락률 순으로 정렬해 추천 후보 도출
                                1~3순위에 투자금을 50/30/20% 비율로 배분,
                                현재가 기준 매수 가능 정수 주수·잔액까지 계산
      │
      ▼
[결과 화면]                    밸류체인 네트워크 그래프, 종목별 상태 테이블(CSV 다운로드),
                                추천 후보 카드, 투자금 배분표
```

## 주요 기능

- **오늘의 추천 이슈**: OpenAI Responses API의 `web_search` 도구로 오늘 화제성 있는 산업 이슈 5개를
  검색해 순위와 함께 드롭다운으로 제공 (하루 1회 자동 캐싱, 수동 새로고침 가능)
- **GraphRAG 기반 밸류체인 추론**: LLM이 추출한 노드/엣지를 그래프로 구성해 대장주 대비 hop 거리로
  1차/2차/3차 수혜주를 구분
- **다층 검증 필터**
  - KRX 종목코드 실존 여부 검증 (LLM 환각·사명 변경 종목 자동 제외)
  - 이미 급등(기본 15% 이상)한 종목 제외
  - "불구하고/그럼에도" 식 우회 논리가 담긴 근거 텍스트 결정론적 제외
  - `/theme-validate` 커맨드로 문구 필터를 통과했더라도 의미상 우회 논리·판매자/구매자 혼동 등을
    2차로 교차 검증 가능 (`.claude/commands/theme-validate.md`)
- **밸류체인 네트워크 시각화**: plotly 기반 그래프로 상태별(대장주/추천/제외/미확인) 색상 구분
- **투자금 배분**: 추천 우선순위 1~3위에 투자금을 차등 배분하고 실제 매수 가능 주수·잔액 계산
- **CSV 내보내기**, 진행률 표시, 세션 상태 유지(다운로드 클릭 등으로 결과가 사라지지 않음)

## 설치 및 실행 방법

### 1. 환경 설정

Python 3.10 이상 필요. 프로젝트 루트에서 가상환경을 만들고 의존성을 설치합니다.

```bash
python -m venv .venv
# Windows
.venv\Scripts\pip install -r requirements.txt
# macOS/Linux
.venv/bin/pip install -r requirements.txt
```

`.env.example`을 `.env`로 복사한 뒤 OpenAI API 키를 입력합니다.

```bash
cp .env.example .env
# .env 파일을 열어 OPENAI_API_KEY=sk-... 로 실제 키 입력
```

### 2. 실행

```bash
# Windows
.venv\Scripts\streamlit run app.py
# macOS/Linux
.venv/bin/streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

### 3. 사용 순서

1. 사이드바에서 이슈 입력 방식 선택 — **오늘의 추천 이슈**(드롭다운에서 선택) 또는 **직접 입력**
2. 급등 제외 기준(%), 조회 기간(거래일)을 필요에 따라 조정
3. **분석 시작** 클릭 → 밸류체인 네트워크, 종목별 상태 테이블, 추천 후보 카드 확인
4. 필요 시 사이드바에서 투자 가능 금액을 입력하면 1~3순위 배분 결과가 표시됨
5. **결과 CSV 다운로드**로 전체 조회 결과를 내보낼 수 있음

## 참고 / 알려진 제한사항

- FinanceDataReader는 KRX(국내) 상장 종목 위주로 지원하므로, 밸류체인 매핑은 국내 종목 중심입니다.
- LLM이 제시한 종목명은 KRX 목록과 대조해 검증하지만, 사명이 최근 바뀐 종목(예: 옛 사명으로 응답)은
  "미확인 종목"으로 표시되어 놓칠 수 있습니다.
- "오늘의 추천 이슈"의 순위는 실시간 검색량 통계가 아니라, 웹 검색 결과를 바탕으로 한 LLM의
  화제성 판단 기준입니다.
- 투자금 배분(50/30/20%)은 단순 우선순위 기반 배분 규칙이며, 실제 포트폴리오 최적화 알고리즘이
  아닙니다.
- 본 도구는 참고용이며 투자 조언이 아닙니다.
